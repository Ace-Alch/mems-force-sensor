# MEMS Force Sensor: design record

## Purpose

Design and simulate a microscale force sensor.

## Elements

| Element | Documentation boundary |
| :-- | :-- |

| Material model | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Boundary conditions | Included in the stated project scope. Implementation details need the corresponding source or design file. |
| Force response | Included in the stated project scope. Implementation details need the corresponding source or design file. |

## Technical stack

- CATIA
- COMSOL
- MEMS
- Multiphysics

## Boundaries

Part numbers, interfaces, versions and measured outcomes must come from the original artifacts. They are not inferred from the project title.

## Decisions to recover

Record each design decision with its problem, selected option, rejected options and supporting artifact. Keep the original model or source revision with the record.
